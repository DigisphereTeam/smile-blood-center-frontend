# Folder Structure

```
src/
│
├── app/
├── assets/
├── components/
├── constants/
├── context/
├── features/
│   ├── auth/
│   ├── dashboard/
│   ├── frontdesk/
│   └── lab/
├── hooks/
├── layouts/
├── lib/
├── routes/
├── utils/
```

## Folder Rules

- Shared components → components/
- Feature components → features/
- Shared hooks → hooks/
- Feature hooks → feature/hooks/
- Shared utils → utils/
- Feature utils → feature/utils/
- Shared constants → constants/
- Feature constants → feature/constants/
- Axios → lib/
- Query Client → lib/
